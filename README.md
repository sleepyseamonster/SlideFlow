SlideFlow
=========

## Quick start (local dev)
From `SlideFlow/`:

```bash
npm install
npm run dev
```

If the app needs Supabase locally, create an untracked `.env.local` with:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
